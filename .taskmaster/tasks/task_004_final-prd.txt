• ConnectionManager now tracks a last_emission_times dictionary keyed by simulation ID.  
• Throttle interval fixed at 0.2 s; _broadcast_progress() computes elapsed time since last emission.

Implemented ConnectionManager providing robust multi-client handling:

• Keeps per-simulation sets of WebSocket objects in thread-safe active_connections dict.  
• connect(simulation_id, ws): registers socket, spawns background broadcast task and per-client queue if first listener.

• Supports unlimited simultaneous viewers of the same simulation without message loss.
