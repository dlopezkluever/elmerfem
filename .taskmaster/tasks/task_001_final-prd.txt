## 3. Set Up Docker Socket for In-Container Orchestration [done]
### Dependencies: None
### Description: Pass '/var/run/docker.sock' as a read-only volume to the backend and ElmerFEM containers to allow in-container orchestration capabilities.
### Details:
Configure the Docker Compose file to mount '/var/run/docker.sock' as a read-only volume in the backend and ElmerFEM containers. This setup enables the containers to interact with the Docker daemon for orchestration tasks.
<info added on 2025-07-27T10:14:18.311Z>
Updated implementation: docker-compose.yml now mounts /var/run/docker.sock into the backend service only, declared as read-only:

  backend:
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock:ro

ElmerFEM (solver) and all other services run without Docker socket access because they do not initiate or manage containers. The backend can now inspect, start and stop containers as part of the orchestration workflow, fulfilling the subtask’s objective.
