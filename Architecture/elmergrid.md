# **elmergrid Directory Architecture**

## **Purpose**
The `elmergrid` directory contains the source code for the ElmerGrid mesh generation and manipulation tool. Its primary purpose is to discretize geometric domains into finite element meshes and perform various mesh-related operations for Elmer FEM simulations. ElmerGrid serves as a crucial preprocessing component that transforms geometric definitions into computational meshes suitable for finite element analysis.

## **Key Components/Subdirectories**
* **`src/`**: Contains the core C source files for ElmerGrid functionality:
  - `fempre.c`: Main program entry point and command-line interface
  - `egmesh.c` (268KB): Core mesh generation and manipulation routines
  - `egconvert.c` (193KB): Mesh format conversion utilities
  - `egparallel.c` (139KB): Parallel mesh partitioning and MPI-related operations
  - `egnative.c` (175KB): Native Elmer mesh format handling
  - `egextra.c` (39KB): Additional utility functions and mesh operations
  - `egexport.c` (26KB): Export functionalities for various mesh formats
  - `egutils.c` (18KB): General utility functions
  - `egtypes.h` (15KB): Data structure definitions and type declarations
  - `metis-5.1.0/`: METIS library for advanced mesh partitioning
* **`tests/`**: Test cases and validation scripts for ElmerGrid functionalities
* **Configuration files**: CMakeLists.txt, config.h.cmake for build system
* **Documentation**: README.md with basic usage information

## **Functionality/Role in Architecture**
ElmerGrid is a critical preprocessing component in the Elmer FEM workflow with the following key functionalities:

**Mesh Generation:**
- Creates structured 2D meshes consisting of quadrilaterals (4, 5, 8, 9, 12, 16-node) or triangles (3, 6, 10-node)
- Limited 3D functionality through mesh extrusion, creating hexahedrons (8, 20, 27-node) or prisms (6-node)
- Supports geometric primitives and simple domain definitions

**Mesh Import/Export:**
- Reads multiple mesh formats: Gmsh (.msh), UNIVERSAL file format, COMSOL mphtxt files
- Exports primarily to Elmer input/output formats and VTK format
- Converts between different mesh formats for interoperability

**Mesh Manipulation:**
- Geometric operations: scaling, rotation, translation, cloning
- Mesh extrusion for 3D mesh generation from 2D patterns
- Boundary condition assignment during mesh generation
- Mesh quality improvement and optimization

**Parallel Processing Support:**
- Mesh partitioning for parallel computing using internal geometric division
- Integration with METIS library for advanced graph-based partitioning
- MPI-aware mesh distribution for parallel solver execution

## **Inputs and Outputs**
**Inputs:**
- Geometric definition files (`.grd` format) describing simple domains
- External mesh files in various formats (`.msh`, `.neu`, `.mphtxt`, etc.)
- Command-line parameters specifying mesh operations and options
- Partitioning specifications for parallel processing

**Outputs:**
- Elmer Mesh Format files (`mesh.header`, `mesh.nodes`, `mesh.elements`, `mesh.boundary`)
- Partitioned mesh files for parallel simulations (`partitioning.{partition_id}.*`)
- VTK format files for visualization
- Converted mesh files in target formats

## **Interactions with other components**
**Upstream Dependencies:**
- **METIS library**: Provides advanced graph-based mesh partitioning algorithms
- **System libraries**: Standard C libraries for file I/O, mathematical operations

**Downstream Consumers:**
- **`fem/src/ElmerSolver`**: Consumes mesh files generated by ElmerGrid for finite element simulations
- **`ElmerGUI`**: Can invoke ElmerGrid for mesh generation and utilize its output
- **`post/`**: Post-processing tools read mesh data for visualization and analysis
- **External tools**: VTK-compatible visualization software can read ElmerGrid's VTK output

**Data Flow:**
1. ElmerGrid reads geometric definitions or existing meshes
2. Processes and manipulates mesh data according to specified operations
3. Outputs mesh files in Elmer format for solver consumption
4. Provides partitioned meshes for parallel execution environments

**Command-Line Usage Examples:**
```bash
# Generate mesh from geometric definition
ElmerGrid 1 2 rectangle.grd

# Convert Gmsh mesh to Elmer format
ElmerGrid 14 2 mesh.msh

# Partition mesh for 4 processors using METIS
ElmerGrid 2 2 mesh -metis 4

# Scale and rotate mesh
ElmerGrid 2 2 mesh -scale 2.0 2.0 1.0 -rotate 0.0 0.0 45.0
```

**Integration Points:**
- **Mesh Header Files**: `mesh.header` contains mesh metadata consumed by ElmerSolver
- **Boundary Data**: `mesh.boundary` provides boundary condition information
- **Partitioning Info**: Used by parallel solver for domain decomposition
- **VTK Output**: Enables integration with external visualization pipelines
