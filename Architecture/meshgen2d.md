# **meshgen2d Directory Architecture**

## **Purpose**
The `meshgen2d` directory contains the Mesh2D application, a specialized 2D mesh generator for Elmer FEM. It provides automated triangular and quadrilateral mesh generation for 2D computational domains, with particular focus on boundary layer mesh generation and advanced mesh quality optimization using Voronoi-based algorithms.

## **Key Components/Subdirectories**
* `src/`: Core source directory containing C++ implementation
  * `main.cpp`: Main entry point and command-line interface
  * `MeshParser.cpp`: Input file parsing and geometry interpretation
  * `Mesh.cpp`: Main mesh data structure and mesh generation algorithms
  * `include/`: Header files defining class interfaces and data structures
* Geometry and topology classes:
  * `GeometryEdge.cpp`, `GeometryNode.cpp`: Geometric boundary representation
  * `Body.cpp`, `BoundaryElement.cpp`: Domain and boundary definitions
* Element generation:
  * `TriangleElement.cpp`, `QuadElement.cpp`: Element creation and validation
  * `TriangleNELayer.cpp`, `QuadLayer.cpp`: Structured layer generation
* Advanced meshing algorithms:
  * `Vertex.cpp`, `VoronoiVertex.cpp`: Vertex management and Voronoi computations
  * `VoronoiSegment.cpp`: Voronoi diagram-based mesh optimization
  * `Connect.cpp`: Element connectivity and topology management
* Background mesh support:
  * `BGGridMesh.cpp`, `BGTriangleMesh.cpp`: Background mesh for size control
* `CMakeLists.txt`: Build configuration
* `config.h.cmake`: Configuration template

## **Functionality/Role in Architecture**
Mesh2D serves as a preprocessing component in the Elmer FEM workflow, specializing in 2D mesh generation with advanced features:

* **Automatic Mesh Generation**:
  * Triangular mesh generation using advancing front and Delaunay algorithms
  * Quadrilateral mesh generation with structured and unstructured approaches
  * Hybrid mesh generation combining triangles and quadrilaterals

* **Boundary Layer Mesh Generation**:
  * Specialized algorithms for generating prismatic boundary layers
  * Critical for accurate simulation of boundary layer effects in fluid dynamics
  * Anisotropic mesh stretching near walls and boundaries

* **Advanced Mesh Quality Control**:
  * Voronoi-based mesh optimization for improved element quality
  * Adaptive mesh refinement based on geometric criteria
  * Background mesh-driven size control and grading

* **Geometry Processing**:
  * Reads and processes 2D geometric definitions
  * Handles complex boundary geometries with curves and corners
  * Automatic geometry cleanup and mesh compatibility checks

* **Mesh Format Output**:
  * Generates Elmer-compatible mesh files
  * Supports boundary condition assignment during mesh generation
  * Element and node numbering for optimal solver performance

## **Inputs and Outputs**
* **Inputs:**
  * 2D geometry definition files (various formats supported)
  * Mesh density specifications and size control parameters
  * Background mesh files for adaptive sizing (`--bgmesh`, `--bgcontrol` options)
  * Boundary layer specifications (thickness, growth rates, number of layers)
  * Mesh quality criteria and optimization parameters

* **Outputs:**
  * Elmer mesh format files (nodes, elements, boundary elements)
  * Mesh statistics and quality reports
  * Element connectivity information for efficient solver operations
  * Boundary condition assignments and material identifiers

## **Interactions with other components**
* **`elmergrid`**: May work in conjunction with ElmerGrid for mesh format conversion and 3D extrusion
* **`ElmerGUI`**: The GUI can invoke Mesh2D for automated 2D mesh generation from geometric models
* **`fem/src/ElmerSolver.F90`**: ElmerSolver reads mesh files generated by Mesh2D for 2D and 2.5D simulations
* **External CAD tools**: Can process geometry exported from CAD systems
* **`post/` directory**: Generated meshes are used by post-processing tools for visualization
* **User workflow**: Typically used as: Geometry → Mesh2D → ElmerSolver → Post-processing

## **Example Files/Code Snippets (if applicable)**
* **Command-line usage:**
  ```bash
  Mesh2D --bgmesh=background.mesh --bgcontrol=control.txt input.geo mesh_output_dir
  ```

* **Key classes and functionality:**
  * `MeshParser`: Handles input file parsing and geometry setup
  * `Mesh`: Main mesh generation coordinator class
  * `TriangleNELayer`: Implements boundary layer mesh generation algorithms
  * `VoronoiSegment`: Advanced mesh optimization using Voronoi diagrams

* **Typical workflow:**
  1. Parse input geometry and meshing parameters
  2. Generate initial boundary mesh
  3. Create interior mesh using triangulation algorithms
  4. Generate boundary layers if specified
  5. Optimize mesh quality using Voronoi-based methods
  6. Output final mesh in Elmer format

* **Advanced features:**
  * **Background mesh control**: Adaptive mesh sizing based on solution gradients
  * **Boundary layer meshing**: Essential for CFD applications requiring accurate near-wall resolution
  * **Voronoi optimization**: Improves mesh quality by optimizing vertex positions

Mesh2D provides sophisticated 2D mesh generation capabilities that are essential for high-quality finite element simulations, particularly in fluid dynamics and heat transfer applications where boundary layer resolution is critical.
