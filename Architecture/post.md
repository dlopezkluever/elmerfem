# **post Directory Architecture**

## **Purpose**
The `post` directory contains ElmerPost, a comprehensive 3D visualization and post-processing application for finite element analysis results. Its primary purpose is to provide advanced visualization capabilities, data analysis tools, and interactive exploration of simulation results generated by ElmerSolver. ElmerPost serves as the primary tool for interpreting, analyzing, and presenting FEM simulation data through sophisticated graphical rendering, contouring, streamline visualization, and animation capabilities.

## **Key Components/Subdirectories**
* **`src/`**: Core source code directory containing the main ElmerPost application:
  - **`ElmerPost.c` (92KB)**: Main application entry point and core functionality
  - **`graphics/`**: Low-level graphics rendering and OpenGL interface routines
  - **`visuals/`**: High-level visualization modules for specific plot types:
    - `arrows.c`: Vector field visualization and arrow plots
    - `contour_lines.c`: Contour line generation and rendering
    - `isosurface.c`: 3D isosurface extraction and visualization
    - `mesh.c`: Mesh wireframe and surface rendering
    - `particles.c`: Particle tracking and streamline visualization
    - `sphere.c`: Spherical object rendering and manipulation
  - **`objects/`**: Geometric object management and 3D transformations
  - **`modules/`**: Tcl/Tk integration modules for scripting interface
  - **`tcl/`** & **`tk/`**: Tcl/Tk script libraries and GUI components
  - **`elements/`**: Finite element type handling and interpolation routines
  - **`camera/`**: 3D camera control and viewing transformation management
  - **`fonts/`**: Text rendering and font management systems
  - **`help/`**: Integrated help system and documentation
* **`doc/`**: Documentation directory with HTML help files and user guides
* **`matc/`**: MATC (Matrix Calculator) integration for mathematical expressions
* **`data/`**: Sample data files and example visualization scripts
* **Configuration files**: CMakeLists.txt, Tcl/Tk license files, and build configurations

## **Functionality/Role in Architecture**
ElmerPost serves as the primary post-processing and visualization component in the Elmer FEM workflow:

**3D Visualization and Rendering:**
- Advanced OpenGL-based 3D graphics rendering with hardware acceleration
- Real-time interactive manipulation of 3D scenes with rotation, zoom, and panning
- Multiple rendering modes including wireframe, solid, transparent, and textured surfaces
- Lighting models and shading techniques for realistic visualization
- Support for multiple viewports and synchronized multi-window displays

**Scientific Data Visualization:**
- Contour plotting with customizable color scales and isoline generation
- Vector field visualization through arrow plots and streamlines
- Isosurface extraction and rendering for 3D scalar field analysis
- Particle tracking and flow visualization for fluid dynamics results
- Animation capabilities for transient simulation results

**Data Analysis and Processing:**
- Interactive probing and measurement tools for quantitative analysis
- Cross-sectional analysis with cutting planes and slicing operations
- Statistical analysis tools for field variables and simulation results
- Data filtering and threshold operations for focused visualization
- Mathematical expression evaluation through MATC integration

**User Interface and Interaction:**
- Comprehensive Tcl/Tk-based graphical user interface
- Script-based automation and batch processing capabilities
- Interactive mouse and keyboard controls for 3D navigation
- Customizable toolbars, menus, and dialog systems
- Integrated help system with context-sensitive documentation

**File Format Support:**
- Native reading of Elmer result files and mesh formats
- Import capabilities for various FEM solver output formats
- Export functionality for images, videos, and data files
- Support for standard graphics formats (PNG, JPEG, PostScript)

## **Inputs and Outputs**
**Inputs:**
- Elmer result files (`.ep` format) containing simulation data and mesh information
- Elmer mesh files (`mesh.header`, `mesh.nodes`, `mesh.elements`, `mesh.boundary`)
- Configuration files specifying visualization parameters and settings
- Tcl/Tk script files for automated visualization and batch processing
- External data files in various scientific computing formats
- User interaction through mouse, keyboard, and GUI controls

**Outputs:**
- Interactive 3D visualizations displayed in real-time OpenGL windows
- High-quality rendered images in multiple formats (PNG, JPEG, TIFF, PostScript)
- Animation sequences and video files for transient simulation results
- Quantitative analysis results and measurement data
- Publication-quality graphics for scientific papers and presentations
- Session files preserving visualization state and camera positions

## **Interactions with other components**
**Primary Data Sources:**
- **`fem/src/ElmerSolver`**: Consumes result files generated by finite element solver
- **`elmergrid`**: Reads mesh data for geometric visualization and boundary identification
- **External FEM solvers**: Imports results from compatible finite element analysis tools

**Integration Points:**
- **`ElmerGUI`**: Can launch ElmerPost directly from GUI for integrated workflow
- **MATC library**: Utilizes mathematical expression parser for data manipulation
- **System graphics**: Leverages OpenGL and system graphics drivers for hardware acceleration
- **Tcl/Tk framework**: Provides scripting interface and GUI component framework

**Output Consumers:**
- **Documentation systems**: Generates images and animations for technical reports
- **Academic publications**: Produces publication-quality figures and visualizations
- **Presentation software**: Exports graphics for conference presentations and lectures
- **Web platforms**: Creates images and animations for online documentation

**Workflow Integration:**
1. ElmerSolver generates result files during simulation execution
2. ElmerPost loads mesh geometry and solution data from result files
3. User configures visualization parameters through GUI or scripts
4. Real-time 3D rendering displays simulation results with interactive controls
5. Advanced visualization techniques reveal flow patterns, stress distributions, and field behaviors
6. Analysis tools extract quantitative information and measurements
7. Export capabilities generate publication-ready graphics and animations
