# Educational Mesh Generator for ElmerFEM

This directory contains a custom, streamlined mesh generator specifically designed for educational finite element analysis workflows with ElmerFEM.

## Overview

The Educational Mesh Generator provides fast, simplified mesh generation for standard geometries commonly used in educational FEM simulations. It generates meshes directly in ElmerFEM's native format, eliminating the need for complex preprocessing steps.

## Features

- **Supported Geometries** (currently stubbed, full implementation pending):
  - Rectangle (basic implementation)
  - Circle
  - Annulus
  - L-Shape

- **C/Python Interoperability**: The Fortran module is compiled as a shared library with C bindings for easy integration with Python
- **Direct ElmerFEM Format**: Generates mesh files directly in ElmerFEM's native format (mesh.header, mesh.nodes, mesh.elements, mesh.boundary)
- **Quality Metrics**: Returns mesh quality information including element count, node count, and aspect ratios

## Files

- `educational_mesh_generator.F90` - Main Fortran module with mesh generation routines
- `Makefile` - Build configuration for creating the shared library
- `test_library.py` - Python test script to verify library loading and basic functionality
- `libeducational_mesh.so` - Compiled shared library (generated by make)

## Usage

### From Python
```python
import ctypes
from pathlib import Path

# Load the library
lib = ctypes.CDLL('./libeducational_mesh.so')

# Define structures matching Fortran types
class GeometryParams(ctypes.Structure):
    _fields_ = [
        ("geometry_type", ctypes.c_int),      # 1=rect, 2=circle, 3=annulus, 4=L
        ("params", ctypes.c_double * 10),     # Geometry-specific parameters
        ("mesh_density", ctypes.c_int),       # 1-5 (coarse to fine)
        ("boundary_layer", ctypes.c_int)      # 0=false, 1=true
    ]

class MeshQuality(ctypes.Structure):
    _fields_ = [
        ("min_angle", ctypes.c_double),
        ("max_angle", ctypes.c_double),
        ("aspect_ratio_avg", ctypes.c_double),
        ("aspect_ratio_max", ctypes.c_double),
        ("total_elements", ctypes.c_int),
        ("total_nodes", ctypes.c_int),
        ("return_code", ctypes.c_int)          # 0=success
    ]

# Set up function signature
generate_mesh = lib.generate_mesh
generate_mesh.argtypes = [
    ctypes.POINTER(GeometryParams),
    ctypes.c_char_p,
    ctypes.POINTER(MeshQuality)
]

# Create rectangle mesh
geometry = GeometryParams()
geometry.geometry_type = 1    # Rectangle
geometry.params[0] = 2.0      # Width
geometry.params[1] = 1.0      # Height
geometry.mesh_density = 3     # Medium density

quality = MeshQuality()
output_dir = b"/path/to/output"

generate_mesh(ctypes.byref(geometry), output_dir, ctypes.byref(quality))
print(f"Generated mesh with {quality.total_elements} elements")
```
